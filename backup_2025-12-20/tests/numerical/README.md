# Numerical Correctness Tests

This directory contains numerical validation tests that verify Spectral Predict's preprocessing implementations produce identical results to validated external implementations.

## Overview

All tests use gold standard reference data generated by `scripts/generate_gold_standards.py`, which creates deterministic test cases using:

- **SNV**: Direct formula implementation `(X - mean) / std`
- **Savitzky-Golay derivatives**: `scipy.signal.savgol_filter`
- **PLS**: `sklearn.cross_decomposition.PLSRegression`
- **Baseline correction**: `numpy.polyfit` polynomial fitting

## Test Structure

### Gold Standard Files

Located in `tests/gold_standards/`:

- `snv_outputs.npz`: SNV transformation reference data
- `derivatives.npz`: Savitzky-Golay derivative reference data (1st, 2nd)
- `pls_outputs.npz`: PLS regression coefficients and scores
- `baseline_outputs.npz`: Polynomial baseline correction reference
- `edge_cases.npz`: Edge case scenarios (single sample, constant values, small windows)

### Test Modules

- `test_preprocessing_correctness.py`: Main numerical validation tests

## Running Tests

```bash
# Run all numerical tests
pytest tests/numerical/ -v

# Run only numerical marker
pytest -m numerical -v

# Run with detailed output
pytest tests/numerical/test_preprocessing_correctness.py -v --tb=short

# Run specific test class
pytest tests/numerical/test_preprocessing_correctness.py::TestSNVCorrectness -v
```

## Tolerance Levels

Tests use strict tolerances appropriate for each operation:

- **1e-10**: Exact mathematical operations (SNV)
- **1e-12**: scipy derivative operations (Savitzky-Golay)
- **1e-10**: Polynomial baseline correction

## Regenerating Gold Standards

If preprocessing implementations change, regenerate gold standards:

```bash
python scripts/generate_gold_standards.py
```

This will create new reference files in `tests/gold_standards/`.

**IMPORTANT**: Only regenerate if you are certain the new implementation is correct. Gold standards should be validated against external tools before replacing.

## Test Categories

### SNV Tests
- Match against gold standard formula
- Single sample handling
- Constant values (zero variance)
- Determinism
- Shape preservation

### Savitzky-Golay Tests
- 1st derivative matches scipy
- 2nd derivative matches scipy
- Alternative parameters
- Small windows
- Even window auto-increment
- Default polyorder selection
- Determinism

### Baseline Tests
- Polynomial baseline matches numpy.polyfit
- Single spectrum handling
- Linear baseline (degree=1)
- Determinism
- Shape preservation

### Pipeline Tests
- SNV → Derivative combination
- Derivative → SNV combination

### Input Validation Tests
- Window size validation
- Polyorder validation
- Feature count validation

## Adding New Tests

1. Generate gold standard data in `scripts/generate_gold_standards.py`
2. Add test function to `test_preprocessing_correctness.py`
3. Use `@pytest.mark.numerical` decorator
4. Use appropriate tolerance for `np.testing.assert_allclose()`
5. Verify test passes and is deterministic

## Determinism

All tests are deterministic and use fixed random seeds (42) where applicable. Running tests multiple times should produce identical results:

```bash
# Run tests 3 times to verify determinism
for i in {1..3}; do pytest tests/numerical/ -q; done
```

All 24 tests should pass on every run.
