# Performance Bottleneck Quick Reference

## Key Files for Optimization

### Primary Bottleneck: search.py (36 KB, 819 lines)
**Location:** `/home/user/dasp/src/spectral_predict/search.py`

**Critical Function:** `run_search()` (lines 20-450)
- Nested loop structure: preprocessing → models → CV folds → variables → regions
- Calls: `_run_single_config()` repeatedly
- Generates: 10,000+ model fit operations for comprehensive search

**Optimization Opportunities:**
1. **Line 300-370**: Main model testing loop - parallelize with `joblib.Parallel`
2. **Line 260-299**: Preprocessing loop - cache results instead of recomputing
3. **Line 349-450**: Variable subset testing - implement early stopping

**Quick Win:** Add `n_jobs=-1` to parallelize model grid

### Secondary Bottleneck: variable_selection.py (28 KB, 400+ lines)
**Location:** `/home/user/dasp/src/spectral_predict/variable_selection.py`

**Functions:**
- `uve_selection()` - Uses PLS across CV folds on augmented data (O(n×p×k))
- `spa_selection()` - Successive projections with random starts (O(p²))
- `ipls_selection()` - Interval PLS testing (O(p/interval))

**Estimated Impact:** 5-20 minutes for comprehensive variable selection

**Optimization Strategy:**
- Cache random noise augmentation (UVE)
- Reduce SPA random starts
- Use fewer intervals for iPLS

### Tertiary Bottleneck: neural_boosted.py (15 KB, 400+ lines)
**Location:** `/home/user/dasp/src/spectral_predict/neural_boosted.py`

**Class:** `NeuralBoostedRegressor`
- Sequential weak learner training (can't be parallelized directly)
- Each estimator trains on residuals (dependent on previous)
- Estimated per-fold time: 10-30 seconds

**Optimization Opportunity:**
- Reduce `max_iter` parameter (currently 500, could be 100-200)
- Reduce `n_estimators` (currently 100, could be 50)
- Implement early stopping based on validation loss

## Performance Characteristics by Module

### Preprocessing (preprocess.py) - ~0.1-1 second per call
```
SNV transform:     O(n × p)     - 100 samples × 2000 features = 10ms
SG Derivative:     O(n × p)     - 100 samples × 2000 features = 50ms
Full pipeline:     O(n × p)     - 100 samples × 2000 features = 100-200ms
```
**Current issue:** Computed separately for each preprocessing config in search loop

### Model Fitting - varies by model
```
PLS:              0.5-2 sec      - SVD on preprocessed data
Ridge/Lasso:      0.1-0.5 sec    - Closed-form or ADMM
RandomForest:     5-10 sec       - 200 trees × split evaluation
MLP:              2-5 sec        - Neural network training
NeuralBoosted:    10-30 sec      - Sequential weak learner boosting
```

### Cross-Validation Loop
```
K-Fold CV (5 folds):
  - Split creation:  1-2 ms
  - Per-fold:        Model fitting × 5
  - Total per config: Model_time × 5 folds
```

### Variable/Region Subsets
```
Variable subsets:  
  - Top-N selection:  10-50 ms
  - Per-subset fit:   Model_time (reduced feature count helps a bit)
  - Total per model:  Model_time × 5 configs × 5 folds = Model_time × 25

Region subsets:
  - Detection:       100-500 ms (one-time per preprocessing)
  - Per-region fit:  Model_time (reduced feature count helps more)
  - Total per model: Model_time × 10-20 regions × 5 folds = Model_time × 50-100
```

## Quick Parallelization Template

To parallelize the main search loop in `search.py`:

```python
# Current (sequential):
for preprocess_cfg in preprocess_configs:
    for model_name, model_configs in model_grids.items():
        for model, params in model_configs:
            result = _run_single_config(...)
            df_results = add_result(df_results, result)

# Optimized (parallel):
from joblib import Parallel, delayed

configs = [
    (preprocess_cfg, model_name, model, params)
    for preprocess_cfg in preprocess_configs
    for model_name, model_configs in model_grids.items()
    for model, params in model_configs
]

results = Parallel(n_jobs=-1)(
    delayed(_run_single_config)(
        X_np, y_np, wavelengths, model, model_name, params, 
        preprocess_cfg, cv_splitter, task_type, is_binary_classification,
        subset_indices=None, subset_tag="full"
    )
    for preprocess_cfg, model_name, model, params in configs
)

# Aggregate results
for result in results:
    df_results = add_result(df_results, result)
```

Expected speedup: 4-8x on 8-core CPU
Implementation time: ~1-2 hours
Risk: Low (isolated change to main loop)
