## Test Suite 1: Loading Models from Results Tab

### Test 1.1: Load PLS Model (Full Spectrum)

**Objective:** Verify that a PLS model with full spectrum loads correctly into Tab 7.

**Steps:**
1. Load quick_start data (Import & Preview tab)
   - Select `example/` directory for ASD files
   - Select `example/reference.csv` for reference
   - Click "Load Data"
2. Configure analysis (Analysis Configuration tab)
   - Select models: PLS only
   - Preprocessing: raw only
   - Subset methods: full only
   - Set n_folds: 3
3. Run analysis and wait for completion
4. Go to Results tab
5. Find top-ranked PLS result (should have highest R²)
6. **Double-click** the PLS result row

**Expected Results:**
- [ ] Tab 7 (Custom Model Development) opens automatically
- [ ] Mode label shows: "Mode: Loaded from Results (Rank X)"
- [ ] Configuration text displays:
  - [ ] Model name: "PLS"
  - [ ] Rank number
  - [ ] Preprocessing method: "raw"
  - [ ] Performance metrics (R², RMSE)
  - [ ] Wavelength count (should equal total available wavelengths)
- [ ] Wavelength specification field is populated with wavelength list
- [ ] Model type dropdown shows "PLS"
- [ ] n_components spinbox has a value > 0
- [ ] Window size dropdown has a value
- [ ] CV folds spinbox shows 3 (matches analysis)
- [ ] "Run Model" button is enabled

**Verification:**
- [ ] Count wavelengths in specification field (should match "n_vars" from Results)
- [ ] Note original R² value: ___________________

**Pass/Fail:** _______ | **Notes:** _________________________________
