## Method Descriptions

### 1. SPA (Successive Projections Algorithm)

**Reference:** Araújo et al. (2001), Paper Section 4.3.1

**What it does:**
Selects wavelengths with minimal collinearity by iteratively projecting candidates onto orthogonal subspaces.

**Why it's valuable:**
- Existing importance-based selection can choose highly correlated wavelengths
- SPA specifically minimizes collinearity (measured by VIF)
- Better for MLR models which suffer from multicollinearity
- Comparable performance to full-spectrum PLS in many cases

**Key Features:**
- Tests multiple random starting wavelengths (default: 10)
- Selects best via leave-one-out cross-validation
- Returns collinearity measure (VIF)
- Works with any number of target variables

**Example Usage:**
```python
from spectral_predict.variable_selection import SuccessiveProjectionsAlgorithm

spa = SuccessiveProjectionsAlgorithm(
    n_vars=50,
    n_random_starts=10,
    validation_method='loo',
    verbose=True
)

spa.fit(X_spectra, y_target)
X_selected = spa.transform(X_spectra)

print(f"Selected wavelengths: {spa.selected_variables_}")
print(f"Collinearity (VIF): {spa.get_collinearity_measure(X_spectra)}")
```

### 2. UVE (Uninformative Variable Elimination)

**Reference:** Centner et al. (1996), Paper Section 4.3.2

**What it does:**
Filters out variables where noise dominates signal by comparing stability scores to artificial random variables.

**Why it's valuable:**
- Provides objective noise threshold (no guesswork)
- Can eliminate 10-50% of variables as uninformative
- Improves model robustness
- Particularly useful for noisy spectral regions

**Key Features:**
- Adds artificial noise variables as reference
- Calculates stability = mean/std of PLS coefficients
- Adjustable cutoff multiplier (0.7-1.5 typical)
- Returns diagnostic information for visualization

**Example Usage:**
```python
from spectral_predict.variable_selection import UninformativeVariableElimination

uve = UninformativeVariableElimination(
    cutoff_multiplier=1.0,
    n_components=None,  # Auto-determine
    verbose=True
)

uve.fit(X_spectra, y_target)
X_filtered = uve.transform(X_spectra)

print(f"Eliminated: {uve.n_eliminated_} variables")
print(f"Retained: {uve.n_retained_} variables")
```

---

### 3. UVE-SPA Hybrid

**Reference:** Ye et al. (2008), Paper Section 4.3.3

**What it does:**
Two-stage process: (1) UVE filters noise, (2) SPA selects non-collinear subset

**Why it's valuable:**
- Addresses BOTH noise AND collinearity
- Paper shows this outperforms either method alone
- Typical reduction: 80-95% of variables

**Key Features:**
- Automatic two-stage pipeline
- Comprehensive diagnostics from both stages
- Handles edge cases (e.g., UVE eliminates too many variables)

**Example Usage:**
```python
from spectral_predict.variable_selection import UVE_SPA

hybrid = UVE_SPA(
    n_vars=50,
    uve_cutoff_multiplier=1.0,
    uve_n_components=None,
    spa_n_random_starts=10,
    verbose=True
)

hybrid.fit(X_spectra, y_target)
X_selected = hybrid.transform(X_spectra)

summary = hybrid.get_selection_summary()
print(f"Initial: {summary['initial_n_features']}")
print(f"After UVE: {summary['uve_retained']}")
print(f"Final (SPA): {summary['final_n_features']}")
print(f"Total reduction: {summary['total_reduction_pct']:.1f}%")
```

### 4. iPLS (Interval Partial Least Squares)

**Reference:** Nørgaard et al. (2000), Paper Section 4.5.1

**What it does:**
Divides spectrum into intervals, builds separate PLS models for each, ranks by performance

**Why it's valuable:**
- Provides graphical overview of spectral informativeness
- Uses actual PLS performance (not just correlation)
- Can identify optimal spectral windows
- Better than fixed region correlation analysis

**Key Features:**
- Configurable number of intervals (default: 20)
- Optimizes components per interval
- Returns ranked intervals
- Compares to full-spectrum model
- Visualization similar to paper Figure 8

**Example Usage:**
```python
from spectral_predict.variable_selection import IntervalPLS

ipls = IntervalPLS(
    n_intervals=20,
    max_n_components=10,
    optimize_components=True,
    verbose=True
)

ipls.fit(X_spectra, y_target, wavelengths=wavelengths)

best_interval = ipls.get_best_interval()
print(f"Best interval: #{best_interval['interval_idx']}")
print(f"Wavelengths: {best_interval['start_wavelength']:.0f}-{best_interval['end_wavelength']:.0f}nm")
print(f"RMSECV: {best_interval['rmsecv']:.4f}")
print(f"Components: {best_interval['optimal_n_components']}")

# Get visualization data
plot_data = ipls.get_visualization_data()
```

## Integration with search.py

### New Parameters Added

```python
run_search(
    X, y, task_type,
    # ... existing parameters ...
    variable_selection_method='importance',  # NEW: 'importance', 'spa', 'uve', 'uve_spa', 'ipls'
    apply_uve_prefilter=False,              # NEW: Pre-filter with UVE before main method
    uve_cutoff_multiplier=1.0,              # NEW: UVE threshold (0.7-1.5)
    uve_n_components=None,                  # NEW: PLS components for UVE
    spa_n_random_starts=10,                 # NEW: Random starts for SPA
    ipls_n_intervals=20,                    # NEW: Intervals for iPLS
)
```

### How It Works

1. **Backward Compatible:** Default `variable_selection_method='importance'` uses existing feature importance approach

2. **Preprocessing Preserved:** All selection happens on preprocessed data (derivatives, SNV, etc.)

3. **UVE Pre-filter:** Optional noise filtering before any selection method

4. **Flexible:** Each method returns list of variable subsets to test

5. **Results Tracking:** New columns added:
   - `SelectionMethod`: Which method was used
   - `SelectionDiagnostics`: Method-specific diagnostic information

### Example Usage in Workflow

```python
from spectral_predict.search import run_search

# Example 1: Use SPA instead of importance
results_spa = run_search(
    X, y, task_type='regression',
    variable_selection_method='spa',
    variable_counts=[20, 50, 100],  # Will select these with SPA
    spa_n_random_starts=10
)

# Example 2: Use UVE-SPA hybrid
results_hybrid = run_search(
    X, y, task_type='regression',
    variable_selection_method='uve_spa',
    variable_counts=[50],  # Final target after both stages
    uve_cutoff_multiplier=1.0
)

# Example 3: iPLS interval analysis
results_ipls = run_search(
    X, y, task_type='regression',
    variable_selection_method='ipls',
    ipls_n_intervals=20
)

# Example 4: Use importance with UVE pre-filter
results_uve_importance = run_search(
    X, y, task_type='regression',
    variable_selection_method='importance',
    apply_uve_prefilter=True,
    uve_cutoff_multiplier=1.0,
    variable_counts=[20, 50, 100]
)
```

## Technical Implementation Details

### Key Design Decisions

1. **Scikit-learn Compatible:**
   - All classes follow `BaseEstimator` interface
   - `fit()`, `transform()`, `fit_transform()` methods
   - Can be used in sklearn pipelines

2. **Preprocessing Awareness:**
   - Selection happens AFTER preprocessing
   - Handles derivatives correctly (indices map to transformed space)
   - Avoids window size > n_features errors

3. **Comprehensive Diagnostics:**
   - All methods store diagnostic information
   - Enables visualization and interpretation
   - Helps understand WHY variables were selected/eliminated

4. **Robust Error Handling:**
   - Validates inputs
   - Handles edge cases (e.g., all variables eliminated)
   - Informative error messages

5. **Performance:**
   - Parallel execution where appropriate (SPA uses LOO CV)
   - Efficient numpy operations
   - Reasonable computation times

### Important Implementation Notes

#### Preprocessing Order

**CRITICAL:** Variable selection ALWAYS happens on preprocessed data

```python
# Correct workflow:
X_raw → Preprocessing → X_preprocessed → Variable Selection → X_selected

# NOT:
X_raw → Variable Selection → X_selected → Preprocessing (WRONG!)
```

**Why:** Derivatives and SNV change the feature space. Importances must reflect what the model actually sees.

#### Derivative Handling

For derivatives:
- Importances computed on transformed features
- Subset selection uses transformed indices
- Skip reapplying preprocessing (would cause window size errors)

For raw/SNV:
- Importances on preprocessed features
- Can map indices back to wavelengths
- Can reapply preprocessing if needed

## Performance Expectations

### SPA
- **Speed:** Medium (multiple random starts with LOO CV)
- **Typical runtime:** 5-30 seconds for 1000 features, 10 starts
- **Variables selected:** As specified by user
- **Best for:** MLR, datasets with high collinearity

### UVE
- **Speed:** Slow (LOO CV with extended matrix)
- **Typical runtime:** 30-120 seconds for 1000 features
- **Variables retained:** Variable (typically 50-90% retained)
- **Best for:** Pre-filtering noisy regions

### UVE-SPA
- **Speed:** Slow (combines both)
- **Typical runtime:** 1-3 minutes for 1000 features
- **Variables selected:** As specified (after two stages)
- **Best for:** Maximum quality variable selection

### iPLS
- **Speed:** Medium (multiple PLS models)
- **Typical runtime:** 20-60 seconds for 20 intervals
- **Variables selected:** One or more intervals
- **Best for:** Exploring which spectral regions are informative
