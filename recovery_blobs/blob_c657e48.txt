## Technical Highlights

### Architecture

The execution engine implements a **7-step pipeline**:

1. **Parse Parameters** - Extract and validate all UI parameters
2. **Filter Data** - Apply exclusions, validation set, reset index
3. **Build Preprocessing Pipeline** - Determine path (A or B) and configure
4. **Cross-Validation** - Deterministic CV with shuffle=False
5. **Train Final Model** - Fit on full dataset for persistence
6. **Calculate Metrics** - R², RMSE, MAE, bias (regression) or Accuracy, Precision, Recall, F1 (classification)
7. **Update GUI** - Thread-safe results display with plot generation

### Critical Design Decisions

**1. Deterministic CV (shuffle=False)**
- Ensures identical fold splits as Results tab
- Matches Julia backend behavior
- Reproducible results across runs

**2. Index Reset After Exclusions**
- Converts non-sequential indices (e.g., [0,1,2,5,7,9]) to sequential [0,1,2,3,4,5]
- Prevents CV fold mismatches
- Critical for matching Results tab

**3. Two Preprocessing Paths**

**Path A: Derivative + Subset**
- Preprocess FULL spectrum first
- Then subset to selected wavelengths
- Preserves derivative context
- Matches search.py behavior

**Path B: Raw/SNV**
- Subset first
- Then preprocess inside CV
- Standard pipeline behavior

**4. Validation Set Exclusion**
- Excludes validation samples before training
- Matches Results tab calibration split
- Essential for R² matching

**5. Thread-Safe GUI Updates**
- All updates via `self.root.after()`
- Prevents GUI freezing
- Allows responsive UI during long operations

## Performance

### Execution Times (Approximate)

| Configuration | Time |
|--------------|------|
| PLS, 100 samples, 5-fold | 3-5 seconds |
| Ridge, 100 samples, 5-fold | 2-4 seconds |
| RandomForest, 100 samples, 5-fold | 10-20 seconds |
| MLP, 100 samples, 5-fold | 15-30 seconds |
| NeuralBoosted, 100 samples, 5-fold | 30-60 seconds |

**Factors Affecting Time:**
- Dataset size (samples × wavelengths)
- Model complexity
- CV folds (10-fold ≈ 2× slower than 5-fold)
- Preprocessing (derivatives slower than raw)
- Hardware (CPU, RAM)

### Memory Footprint
- Minimal (clones models per fold but releases immediately)
- Stores only final model and predictions
- No memory leaks observed
