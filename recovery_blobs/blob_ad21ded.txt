## Section Details

### 1. Header Section
**Size:** Full width, ~150px height
**Contents:**
- Title (left): "Model Development" (24pt bold)
- Mode label (center): "Mode: Fresh Development" (14pt, green)
- Reset button (right): "🔄 Reset to Fresh" (10pt)
- Config text (below): 5-line read-only text showing model info

**Purpose:** Shows current mode and allows reset

---

### 2. Model Parameters Section
**Size:** Full width, ~400px height
**Layout:** 2 equal columns (50/50 split)

#### Left Column (~40% width)
1. **Model Type** - Combobox (6 options)
2. **Task Type** - Combobox (2 options)
3. **Backend** - Combobox (1 option for now)
4. **Preprocessing** - Combobox (11 options)
5. **Window Size** - Radio buttons (4 options)
6. **CV Folds** - Spinbox (3-10)

#### Right Column (~60% width)
1. **Wavelength Spec** - Text widget (4 lines, scrollable)
2. **Preset Buttons** - 4 buttons (All, NIR, Visible, Custom)
3. **Wavelength Count** - Label (updates real-time)
4. **Hyperparameters** - Dynamic frame (changes with model type)

---

### 3. Actions Section
**Size:** Full width, ~60px height
**Contents:**
- Run button (left): Large accent button
- Save button (right): Regular button, disabled initially

---

### 4. Results Section
**Size:** Full width, ~180px height
**Contents:**
- 8-line text widget showing:
  - Cross-validation metrics
  - R², RMSE, MAE
  - Per-fold results
  - Feature importance (if applicable)

---

### 5. Diagnostic Plots Section
**Size:** Full width, ~280px height
**Layout:** 3 equal columns (33/33/33 split)

#### Plot 1: Prediction (left)
- Observed vs Predicted scatter
- 1:1 reference line
- R² annotation

#### Plot 2: Residuals (center)
- Residuals vs Predicted
- Zero reference line
- Outlier detection

#### Plot 3: Comparison (right)
- Multiple runs comparison
- Bar chart or line plot
- Legend for runs

---

### 6. Status Bar
**Size:** Full width, ~30px height
**Contents:**
- Status label with real-time updates
- Gray text, small font

- Canvas with scrollbar

## Interaction Flow

```
User Action                     → UI Response
─────────────────────────────────────────────────
Select model type               → Hyperparameters update
Type wavelengths                → Count updates (real-time)
Click preset button             → Wavelengths populate
Click "Custom Range"            → Dialog opens
Click "Reset"                   → Confirmation → Reset all
Click "Run Model"               → Status updates → (Phase 4)
Complete run                    → Results show → Save enabled
Click "Save Model"              → File dialog → Save
```

---

## State Transitions

```
Initial State:
├─ Mode: Fresh Development (green)
├─ Config: Fresh mode message
├─ All controls: Default values
├─ Results: Placeholder text
├─ Plots: Placeholder labels
├─ Save button: Disabled
└─ Status: "Ready..."

After Loading Model (Phase 3):
├─ Mode: "Loaded from Results (Rank X)" (blue)
├─ Config: Shows loaded model details
├─ All controls: Populated from model
├─ Results: Previous results (if available)
├─ Plots: Previous plots (if available)
├─ Save button: Enabled if run completed
└─ Status: "Model loaded..."

After Running Model (Phase 4):
├─ Mode: Unchanged
├─ Config: Unchanged
├─ Controls: Unchanged (can be modified)
├─ Results: Shows CV metrics
├─ Plots: Shows diagnostic plots
├─ Save button: Enabled
└─ Status: "Run complete. R²=..."

After Reset:
├─ Return to Initial State
└─ All history cleared
```
