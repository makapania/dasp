## File Structure

### Main Implementation: `PHASE4_TAB7_EXECUTION_IMPLEMENTATION.py`

Contains 5 methods ready for integration:

1. **`_tab7_run_model()`** (~20 lines)
   - Entry point when user clicks "Run Model" button
   - Validates data and parameters
   - Disables button during execution
   - Launches background thread

2. **`_tab7_validate_parameters()`** (~40 lines)
   - Validates wavelength specification
   - Validates model type selection
   - Validates CV folds range (3-10)
   - Shows user-friendly error messages

3. **`_tab7_run_model_thread()`** (~860 lines)
   - Main execution engine (runs in background thread)
   - 7-step pipeline:
     - Step 1: Parse parameters
     - Step 2: Filter data (with validation set exclusion)
     - Step 3: Build preprocessing pipeline (PATH A or B)
     - Step 4: Cross-validation
     - Step 5: Train final model
     - Step 6: Calculate metrics
     - Step 7: Update GUI (thread-safe)

4. **`_tab7_update_results()`** (~50 lines)
   - Updates results display on main thread
   - Formats performance metrics
   - Enables save button on success
   - Triggers diagnostic plots (optional)

5. **`_tab7_save_model()`** (~150 lines)
   - Saves trained model to .dasp file
   - Includes comprehensive metadata
   - Handles validation set info
   - Auto-generates filename with timestamp

## Troubleshooting Guide

### Issue: "R² doesn't match Results tab"

**Possible Causes:**
1. Validation set not excluded properly
2. Index not reset after exclusions
3. Different CV strategy (shuffle=True instead of False)
4. Different preprocessing path used

**Debug Steps:**
1. Check console output for "Excluding X validation samples"
2. Check console output for "Reset index after exclusions"
3. Check console output for "Using KFold (shuffle=False)"
4. Check console output for "PATH A" or "PATH B"
5. Compare sample counts: should match calibration set exactly

**Solution:**
- Ensure `shuffle=False` in KFold/StratifiedKFold
- Ensure index is reset: `X_base_df.reset_index(drop=True)`
- Ensure validation set is excluded before training
- Ensure same preprocessing path as Results tab

---

### Issue: "Error: No valid wavelengths selected"

**Possible Causes:**
1. Wavelength spec doesn't match available wavelengths
2. Wavelength spec parsing failed
3. All wavelengths out of range

**Debug Steps:**
1. Check available wavelengths: `print(self.X_original.columns)`
2. Check wavelength spec text: `print(self.tab7_wl_spec.get('1.0', 'end'))`
3. Try simple spec: `1000-2500` (full range)

**Solution:**
- Use simple range that covers available data
- Check for typos in wavelength spec
- Ensure wavelength columns are numeric

---

### Issue: "GUI freezes during execution"

**Possible Causes:**
1. Execution not running in background thread
2. GUI update not using `self.root.after()`
3. Blocking operation in main thread

**Debug Steps:**
1. Verify thread launch: `threading.Thread(target=self._tab7_run_model_thread).start()`
2. Verify GUI updates use: `self.root.after(0, lambda: self._tab7_update_results(...))`
3. Check for blocking operations (e.g., `time.sleep()`)

**Solution:**
- Always run execution in background thread
- Always update GUI via `self.root.after()`
- Never use blocking operations in main thread

---

### Issue: "Model save fails"

**Possible Causes:**
1. Model not trained yet
2. Permission error (write access)
3. Invalid file path
4. Missing model_io module

**Debug Steps:**
1. Check if model exists: `print(self.tab7_trained_model)`
2. Check file path permissions
3. Try saving to different location
4. Verify import: `from spectral_predict.model_io import save_model`

**Solution:**
- Always train model before saving
- Choose location with write access
- Use .dasp extension
- Ensure model_io module is available
