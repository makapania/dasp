The implementation includes **strict wavelength validation** that NEVER falls back silently:

```python
# For subset models:
if 'all_vars' not in config or not config['all_vars']:
```

## Technical Details

### 7-Step Loading Process

1. **Validate Data Availability**
   - Check X_original, y, wavelengths exist
   - Fail loud if any missing

2. **Build Configuration Info**
   - Extract model name, rank, preprocessing, subset
   - Format performance metrics (RMSE/R² or Accuracy/ROC AUC)
   - Create info_text string

3. **Load Wavelengths with FAIL LOUD Validation** ⚠️ CRITICAL
   - For subset models: Parse all_vars, validate count and existence
   - For full models: Use all available wavelengths
   - NEVER silently fall back

4. **Format Wavelengths**
   - Small lists: Full display
   - Large lists: Condensed with summary

5. **Load Hyperparameters**
   - Handle field name variations (LVs vs n_components vs n_LVs)
   - Extract model-specific hyperparameters
   - Try dedicated fields first, then Params field

6. **Populate GUI Controls**
   - Update all tab7_* controls
   - Set dropdowns, radio buttons, text displays
   - Auto-detect task type from y values

7. **Finalize**
   - Store config as tab7_loaded_config
   - Update mode label to show "Loaded from Results (Rank X)"
   - Enable Run button
   - Update status displays

### Wavelength Validation Logic

```
Is subset model?
├─ YES (subset_tag not in ['full', 'N/A'])
│  ├─ Check: all_vars field exists?
│  │  ├─ NO → FAIL LOUD: "Missing all_vars field"
│  │  └─ YES → Parse all_vars
│  │     ├─ Parse failed? → FAIL LOUD: "Failed to parse"
│  │     ├─ Count mismatch? → FAIL LOUD: "Count mismatch"
│  │     ├─ Invalid wavelengths? → FAIL LOUD: "Invalid wavelengths"
│  │     └─ All valid → Load subset wavelengths ✓
└─ NO (full model)
   └─ Load all available wavelengths ✓
```
