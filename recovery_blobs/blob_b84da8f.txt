**Date:** November 6, 2025

**Status:** ✅ FIXED
**File:** `julia_port/SpectralPredict/src/models.jl:431`

---

## Executive Summary

**The Julia backend has been forcing ALL PLS models to use only 1 component**, regardless of the configured n_components value. This explains why:

1. **All R² values in Results tab are wrong** - Models are using 1 component instead of the optimal number
2. **Model Development gets correct R²** - Python's scikit-learn PLSRegression works correctly
3. **Huge discrepancies** - A model reported as using 1 component might actually perform better with more components

---

## The Bug

### Location
**File:** `julia_port/SpectralPredict/src/models.jl`
**Line:** 431

### Before (BROKEN):
```julia
# For CCA, max components is limited by min dimension of both X and Y
# Since Y is univariate (1 feature), we can only extract 1 component
n_components = min(model.n_components, n_features, size(X, 1), size(Y_mat, 2))
                                                                    ^^^^^^^^^^^^^
                                                                    ALWAYS 1!
```

### Root Cause
The code limits `n_components` to the minimum of:
- `model.n_components` (requested, e.g., 10)
- `n_features` (number of wavelengths, e.g., 350)
- `size(X, 1)` (number of samples, e.g., 49)
- `size(Y_mat, 2)` ← **ALWAYS 1 for univariate regression!**

Since `Y_mat` is reshaped to `(n_samples, 1)` for univariate y, `size(Y_mat, 2)` is always 1.

This means:
```julia
n_components = min(10, 350, 49, 1) = 1  # WRONG!
```

**Every PLS model, regardless of configuration, uses only 1 component.**

## The Fix

### After (FIXED):
```julia
# CRITICAL FIX: For PLS regression with univariate y, we can extract multiple components
# from X that explain y. Do NOT limit by size(Y_mat, 2) which is always 1.
# Max components is limited by: requested components, number of features, number of samples
n_components = min(model.n_components, n_features, size(X, 1))
```

### Why This Works

For PLS regression with univariate y:
- We extract latent variables from X that maximize covariance with y
- We can have multiple components (latent variables) even with scalar y
- Each component captures different aspects of the X-y relationship
- The limit should be: min(requested, n_features, n_samples)

**NOT limited by dimensions of y!**

## Technical Notes

### Why PLS Can Have Multiple Components with Univariate Y

PLS (Partial Least Squares) for regression works by:
1. Finding directions (latent variables) in X that have high covariance with y
2. Each component is orthogonal to previous ones
3. Multiple components can jointly explain y better than one

This is different from CCA (Canonical Correlation Analysis):
- CCA finds correlated components in BOTH X and Y spaces
- When Y is 1D, there's only 1 direction in Y space
- But PLS doesn't need multiple Y dimensions to extract multiple X components

### Comparison to sklearn

Python's `sklearn.cross_decomposition.PLSRegression`:
```python
from sklearn.cross_decomposition import PLSRegression

# This works perfectly fine:
pls = PLSRegression(n_components=10)
pls.fit(X, y)  # y is univariate (n_samples,)

# Creates 10 components from X that explain y
```

Our Julia implementation was incorrectly limiting this to 1 component.
