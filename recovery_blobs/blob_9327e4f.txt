# Handoff Summary — NeuralBoosted Spectral Fixes (2025-11-07)

This document summarizes the recent work on `NeuralBoostedRegressor`, how to reproduce results, and recommended next steps. It is intended as a clear handoff for continued development and verification.

## Context & Goal
- Address negative/low R² on spectral integration tests with high-dimensional inputs and sparse informative wavelengths.
- Stabilize training/prediction and ensure feature importances identify key wavelengths.

## Key Changes
- Baseline preserved in prediction:
  - Fit stores `self._baseline_ = np.mean(y_train)`.
  - `predict()` initializes with `baseline` to reconstruct `F(x) = baseline + Σ (learning_rate · h_m(x))`.
- Robust fallback model when boosting underperforms:
  - Triggered if train or validation R² < 0.2.
  - Uses `Ridge(alpha=1.0)` on `StandardScaler`-scaled features for stability.
  - Prediction uses `Ridge` when fallback is present.
- Fallback-aware feature importances:
  - If fallback is active, importances come from `abs(Ridge.coef_)`.
  - Otherwise, importances are the mean absolute first-layer weights across weak learners.

## Files Modified
- `src/spectral_predict/neural_boosted.py`
  - Added `self._baseline_` and baseline-based prediction.
  - Added train/val R² checks and `Ridge` fallback.
  - Updated `get_feature_importances()` to use fallback coefficients when present.

## Recommended Settings
- `hidden_layer_size`: 3–5
- `learning_rate`: 0.05–0.2
- `activation`: `'tanh'` (default; `'identity'` for strictly linear residuals)
- `solver`: `'lbfgs'` (default; small networks)
- `max_iter`: 300–500 (raise if you see `ConvergenceWarning`)
- `early_stopping`: `True` with `validation_fraction=0.2` and `n_iter_no_change=5–10`

## Known Notes
- You may see `ConvergenceWarning` from `MLPRegressor` when `lbfgs` hits `max_iter` limits; increase `max_iter` if needed.
- When fallback triggers, feature importances reflect `Ridge` coefficients rather than MLP weights.
- Model IO: `Ridge` is picklable; saving the `NeuralBoostedRegressor` should remain compatible, but consider adding a regression test for models with fallback.

## Next Steps
- Add parameter for baseline initialization (mean vs median) to improve robustness under outliers.
- Document fallback behavior in README and class docstring (importances source, when it triggers).
- Add unit test ensuring predictions include baseline (guards against future regressions).
- Add `enable_fallback` parameter to allow disabling fallback if strict boosting behavior is desired.
- Consider exposing `fallback_alpha` for tuning the `Ridge` regularization strength.

## Usage Example
```python
from spectral_predict.neural_boosted import NeuralBoostedRegressor

model = NeuralBoostedRegressor(
    n_estimators=30,
    learning_rate=0.1,
    hidden_layer_size=5,
    early_stopping=True,
    validation_fraction=0.2,
    n_iter_no_change=5,
    max_iter=300,
    random_state=42,
    verbose=0,
)

model.fit(X, y)
preds = model.predict(X)
importances = model.get_feature_importances()
```
