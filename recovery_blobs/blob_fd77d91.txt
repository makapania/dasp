## Troubleshooting

### Error: NameError for 'self.colors'
**Solution:** You're using the right file - colors are defined in `_configure_style()`

### Error: Module import issues
**Solution:** Make sure you're running from the correct directory with all dependencies

### UI looks wrong/cramped
**Solution:** Make sure window is maximized or large enough (GUI uses 'zoomed' state)

### Widgets not responding
**Solution:** Check that helper methods were pasted correctly (need all 8)

### Can't find line numbers
**Solution:** In VS Code: Ctrl+G (go to line), or View → Appearance → Line Numbers

## Common Issues & Fixes

### Issue: Indentation errors
**Fix:** Python requires consistent indentation. Make sure all pasted code uses spaces (not tabs) and aligns with surrounding code.

### Issue: Method not found
**Fix:** Make sure helper methods are inside the class (indented under `class SpectralPredictApp:`)

### Issue: Missing self parameter
**Fix:** All methods should have `self` as first parameter: `def method_name(self, ...)`

### Issue: StringVar not updating
**Fix:** Make sure you're using `.get()` to read and `.set()` to write StringVar values
