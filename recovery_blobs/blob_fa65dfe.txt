## Key Features

### 1. FAIL LOUD Wavelength Validation ⚠️

**NO SILENT FALLBACKS!**

```
Subset model detected → Check all_vars field
                         ├─ Missing? → CRITICAL ERROR (with context)
                         ├─ Parse failed? → CRITICAL ERROR (show content)
                         ├─ Count mismatch? → CRITICAL ERROR (show both counts)
                         ├─ Invalid wavelengths? → CRITICAL ERROR (list invalid)
                         └─ All valid? → Load ✓

Full model detected → Load all wavelengths ✓
```

**Error messages include:**
- Model name and rank for context
- Specific problem description
- Impact explanation (e.g., "would cause R² discrepancies")
- Actionable solution (e.g., "Re-run analysis")

### 3. Comprehensive Hyperparameter Loading

Handles field name variations for all models:

- **PLS:** `LVs` / `n_components` / `n_LVs`
- **Ridge/Lasso:** `Alpha` / `alpha`
- **RandomForest:** `n_estimators` / `n_trees`, `max_depth` / `MaxDepth`, `max_features`
- **MLP:** `Hidden` / `hidden_layer_sizes`, `LR_init` / `learning_rate_init`
- **NeuralBoosted:** `n_estimators`, `LearningRate` / `learning_rate`, `HiddenSize` / `hidden_layer_size`, `Activation` / `activation`

Falls back to parsing `Params` field if dedicated fields not found.

### 4. Intelligent Wavelength Formatting

- **Small lists (≤50 wavelengths):** Full comma-separated display
  ```
  1520.0, 1540.0, 1560.0, 1580.0, ... (all 50 shown)
  ```

- **Large lists (>50 wavelengths):** Condensed format
  ```
  1520.0, 1540.0, 1560.0, ..., 2460.0, 2480.0, 2500.0

  # Total: 2151 wavelengths selected
  # Range: 1520.0 nm to 2500.0 nm
  ```

### 5. Preprocessing Name Conversion

Automatically converts from `search.py` internal naming to GUI naming:

```python
'deriv' + Deriv=1    →  'sg1'
'deriv' + Deriv=2    →  'sg2'
'snv_deriv' + Deriv=1  →  'snv_sg1'
'snv_deriv' + Deriv=2  →  'snv_sg2'
'deriv_snv'         →  'deriv_snv'
'msc_deriv' + Deriv=1  →  'msc_sg1'
'msc_deriv' + Deriv=2  →  'msc_sg2'
'deriv_msc'         →  'deriv_msc'
'raw'               →  'raw'
'snv'               →  'snv'
'msc'               →  'msc'
```

## Common Issues and Solutions

### Issue 1: "NameError: name 'tab7_wl_spec' is not defined"

**Cause:** Tab 7 UI controls not created yet

**Solution:**
- Either create Tab 7 UI controls first
- Or test with Tab 6 temporarily (change to `refine_` namespace for testing)

### Issue 2: Double-clicking loads into Tab 6 instead of Tab 7

**Cause:** Handler not updated yet

**Solution:** Update double-click binding to use `_on_result_double_click_NEW_TAB7`

### Issue 3: Subset model loads full spectrum instead of subset

**Cause:** Validation not failing loud (shouldn't happen with this implementation)

**Solution:** Check console logs - should see "CRITICAL SECTION: FAIL LOUD validation"

### Issue 4: Error dialog appears for valid subset model

**Cause:** all_vars field may be truly missing or malformed

**Solution:**
- Check Results tab - does model have all_vars column?
- Re-run analysis to regenerate results with all_vars field

### Issue 5: Wavelength count shows 0 after loading

**Cause:** `tab7_wl_count_label` may not exist yet

**Solution:** Create label in Tab 7 UI or comment out that line temporarily
