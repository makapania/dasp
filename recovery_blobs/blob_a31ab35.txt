## Core Python Implementation

### src/spectral_predict/ - Main Package (6,400 lines)

**Critical Performance Files:**

1. **search.py** (36 KB, 819 lines)
   - `/home/user/dasp/src/spectral_predict/search.py`
   - PRIMARY BOTTLENECK
   - Main function: `run_search()` (lines 20-450)
   - Contains nested loops for model search

2. **variable_selection.py** (28 KB, 400+ lines)
   - `/home/user/dasp/src/spectral_predict/variable_selection.py`
   - SECONDARY BOTTLENECK
   - Functions: `uve_selection()`, `spa_selection()`, `ipls_selection()`
   - Estimated impact: 5-20 minutes per analysis

3. **neural_boosted.py** (15 KB, 400+ lines)
   - `/home/user/dasp/src/spectral_predict/neural_boosted.py`
   - TERTIARY BOTTLENECK
   - Class: `NeuralBoostedRegressor`
   - Sequential training, 10-30 seconds per fold

**Core Data Processing:**

4. **models.py** (13 KB)
   - `/home/user/dasp/src/spectral_predict/models.py`
   - Model definitions and grid configurations
   - Function: `get_model_grids()` - defines all model parameters
   - Delegates to scikit-learn, joblib (already parallelized)

5. **preprocess.py** (4 KB)
   - `/home/user/dasp/src/spectral_predict/preprocess.py`
   - SNV transform and Savitzky-Golay derivatives
   - Functions: `SavgolDerivative`, `build_preprocessing_pipeline()`
   - Fast: 0.1-0.2 seconds per call

6. **regions.py** (8 KB)
   - `/home/user/dasp/src/spectral_predict/regions.py`
   - Spectral region analysis
   - Function: `create_region_subsets()`
   - Computed once per preprocessing method

7. **scoring.py** (6 KB)
   - `/home/user/dasp/src/spectral_predict/scoring.py`
   - Ranking and composite scoring
   - 90% performance + 10% complexity weight

8. **io.py** (16 KB)
   - `/home/user/dasp/src/spectral_predict/io.py`
   - File I/O for ASD, CSV, SPC formats
   - Functions: `read_asd_dir()`, `read_csv_spectra()`, `align_xy()`
   - NOT a bottleneck (done once at start)

**Supporting Modules:**

9. **diagnostics.py** (7 KB)
   - `/home/user/dasp/src/spectral_predict/diagnostics.py`
   - Residual and leverage analysis
   - Functions: `compute_residuals()`, `compute_leverage()`

10. **outlier_detection.py** (19 KB)
    - `/home/user/dasp/src/spectral_predict/outlier_detection.py`
    - Multiple outlier detection algorithms
    - NOT in main search loop

11. **progress_monitor.py** (16 KB)
    - `/home/user/dasp/src/spectral_predict/progress_monitor.py`
    - Progress tracking and visualization
    - UI only, not computational

12. **interactive.py** (13 KB)
    - `/home/user/dasp/src/spectral_predict/interactive.py`
    - Interactive analysis tools
    - UI only

13. **model_io.py** (16 KB)
    - `/home/user/dasp/src/spectral_predict/model_io.py`
    - Model persistence (save/load)
    - NOT in main search loop

14. **cli.py** (8 KB)
    - `/home/user/dasp/src/spectral_predict/cli.py`
    - Command-line interface
    - Entry point: `main()`

15. **readers/asd_reader.py**

16. **readers/spc_reader.py**

## Julia Implementation

### julia_port/SpectralPredict/src/ - Core Implementation (5,307 lines)

All files use Julia 1.9+ syntax

1. **SpectralPredict.jl** (3.6 KB)
   - `/home/user/dasp/julia_port/SpectralPredict/src/SpectralPredict.jl`
   - Main module (exports all functions)
   - Entry point for Julia code

2. **preprocessing.jl** (403 lines)
   - SNV transform, Savitzky-Golay derivatives
   - Direct equivalent to Python `preprocess.py`
   - Type-stable, optimized for JIT compilation

3. **models.jl** (994 lines)
   - 6 ML models (PLS, Ridge, Lasso, ElasticNet, RandomForest, MLP)
   - Wrappers around MLJ.jl
   - Direct equivalent to Python `models.py`
   - NOTE: NeuralBoosted not yet implemented

4. **cv.jl** (812 lines)
   - K-fold and stratified k-fold cross-validation
   - Direct equivalent to Python CV in `search.py`
   - Supports parallel CV via Threads

5. **regions.jl** (403 lines)
   - Spectral region analysis
   - Direct equivalent to Python `regions.py`

6. **scoring.jl** (350 lines)
   - Ranking and composite scoring
   - Direct equivalent to Python `scoring.py`

7. **search.jl** (819 lines)
   - Main search loop orchestration
   - Function: `run_search()`
   - Direct equivalent to Python `search.py`

8. **io.jl** (787 lines)
   - CSV file I/O
   - Functions: `load_spectral_data()`, `save_results()`
   - Direct equivalent to Python `io.py`

9. **cli.jl** (280 lines)
   - Command-line interface
   - Entry point: `main()`
   - Direct equivalent to Python `cli.py`
