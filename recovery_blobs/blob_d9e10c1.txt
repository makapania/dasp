- 20 intervals for iPLS is typical for spectroscopy

## How to Use (User Guide)

### Basic Usage (Default Behavior)

1. Run GUI: `python spectral_predict_gui_optimized.py`
2. Load data in Tab 1
3. Go to Tab 3 (Analysis Configuration)
4. Leave "Feature Importance (default)" selected
5. Run analysis

**Result:** Identical behavior to pre-implementation GUI (backward compatible).

### Using Advanced Variable Selection

#### Example 1: SPA (Collinearity-Aware Selection)

**When to use:** Your dataset has highly correlated wavelengths (common in spectroscopy)

**Steps:**
1. Tab 3 → Variable Selection Methods section
2. Select ○ SPA (Successive Projections)
3. Optional: Increase "SPA Random Starts" to 20 for better selection (slower)
4. Run analysis

**Expected outcome:** Selected variables will have minimal collinearity (low VIF)

#### Example 2: UVE (Noise Filtering)

**When to use:** Your spectra have noisy regions you want to automatically filter out

**Steps:**
1. Tab 3 → Variable Selection Methods section
2. Select ○ UVE (Uninformative Variable Elimination)
3. Optional: Adjust "UVE Cutoff" (higher = more aggressive filtering)
   - 0.7 = conservative (keeps more variables)
   - 1.0 = standard (default)
   - 1.5 = aggressive (removes more)
4. Run analysis

**Expected outcome:** Typically eliminates 10-50% of variables as uninformative

#### Example 3: UVE-SPA Hybrid (Best Quality)

**When to use:** You want maximum variable quality (both noise-free AND non-collinear)

**Steps:**
1. Tab 3 → Variable Selection Methods section
2. Select ○ UVE-SPA Hybrid
3. Run analysis

**Expected outcome:** Two-stage filtering results in highest quality variable subset (may be slower)

#### Example 4: iPLS (Region Exploration)

**When to use:** You want to discover which spectral regions are most informative

**Steps:**
1. Tab 3 → Variable Selection Methods section
2. Select ○ iPLS (Interval PLS)
3. Optional: Adjust "iPLS Intervals" (more = finer resolution, slower)
4. Run analysis

**Expected outcome:** Results will show performance for each spectral interval

#### Example 5: UVE Pre-filter

**When to use:** You want to apply UVE noise filtering BEFORE your main selection method

**Steps:**
1. Tab 3 → Variable Selection Methods section
2. Select your main method (e.g., Feature Importance)
3. ☑ Check "Apply UVE Pre-filter"
4. Run analysis

**Expected outcome:** Noisy variables removed first, then main selection applied to clean subset

## Technical Details

### Backend Integration

The GUI calls `run_search()` from `src/spectral_predict/search.py` which:

1. Validates variable selection parameters
2. Calls `select_variables_by_method()` from `variable_selection/integration.py`
3. Routes to appropriate method (SPA, UVE, etc.)
4. Returns selected variable indices
5. Continues normal model training with selected subset

### Performance Expectations

| Method | Relative Speed | Typical Runtime (1000 features) |
|--------|---------------|----------------------------------|
| Feature Importance | Fast (baseline) | 30s - 2min |
| SPA | Medium | +5-30s |
| UVE | Slow | +30-120s |
| UVE-SPA | Slow | +1-3min |
| iPLS | Medium | +20-60s |

**Note:** Times are additive to base analysis time and depend on dataset size.

## Questions & Support

### Common Questions

**Q: Should I use SPA or UVE?**
A: Depends on your problem:
- High collinearity (correlated wavelengths) → Use SPA
- Noisy data → Use UVE
- Both issues → Use UVE-SPA hybrid
- Unsure → Stick with Feature Importance (default)

**Q: Why is UVE-SPA slower?**
A: It runs two methods sequentially (UVE first, then SPA), so runtime adds up.

**Q: Can I use variable selection with region analysis?**
A: Yes! The "Enable Spectral Region Analysis" option works with all variable selection methods.

**Q: What if I get poor results with a new method?**
A: Methods perform differently on different datasets. Try multiple methods and compare results. Feature importance is a solid baseline.

**Q: Do I need to understand the methods to use them?**
A: No, but reading `VARIABLE_SELECTION_IMPLEMENTATION.md` helps interpret results. Defaults are sensible for most cases.
